# Pro3 — 海风鹈鹕骑行（Pelican on a Bicycle）

![海风鹈鹕骑行矢量插画](./pelican.svg)

## 文件说明

- [`pelican.html`](./pelican.html) — 纯内联 SVG + 实时双连杆逆向运动学（IK）交互网页：双蹼全程稳固贴合脚踏旋转，支持骑行暂停/继续（`Space`）、车速调节、晨光/落日场景切换、Web Audio 铜铃音效（`B` 或点击铜铃）与一键导出 SVG。
- [`pelican.svg`](./pelican.svg) — 独立纯矢量 SVG 源文件（`1000×680`），内置轻量 CSS 动效，兼容浏览器与独立 SVG 查看器。
