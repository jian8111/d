# pro4 · 鹈鹕骑行记（Pelican Riding a Bicycle）

一个完全使用纯正矢量 **SVG + 原生 HTML / CSS / JavaScript** 构建的「鹈鹕骑自行车」交互式插画作品，全部文件独立整理在 `pro4/` 目录下，不改动仓库根目录及他人文件。

## 目录结构

```text
pro4/
├── index.html           # 交互式展示页面（内联分层 SVG + 控制台 + 机械遥测）
├── styles.css           # 海岸纸张质感原生样式表（支持晨光 / 落日 / 星夜三套主题）
├── app.js               # 双连杆逆运动学腿部解算、齿轮比传动同步、视差滚动与铃铛音频
├── pelican-bicycle.svg  # 独立可单独打开/引用的 1200×760 纯正静态矢量 SVG 文件
└── README.md            # 本说明文档
```

## 核心设计亮点

1. **真实的机械与生物运动学耦合**
   - 前牙盘（28 齿）与后飞轮（13 齿）严格按 `28:13` 传动比带动 18 根交叉辐条车轮旋转。
   - 地面木栈道护栏、路面石缝与自行车道虚线随车轮周长位移同步视差滚动，消除视觉打滑。
   - 鹈鹕双腿采用实时 **双连杆逆运动学（2-link IK）** 解算，无论曲柄转到任意角度，橙色脚蹼始终稳稳踩在左右脚踏上。

2. **海岸鹈鹕与复古巡航车细节**
   - 标志性长上喙钩状尖端、温暖渐变喉囊、金色眼圈与随风飘扬的条纹海岸围巾。
   - 钢架海沫绿复古车架、挡泥板与反光片、镀铬车灯、铜车铃，以及车前竹编车篮中探头的两条海鱼。

3. **丰富交互控制**
   - **暂停 / 继续**（支持 `Space` 空格快捷键）与 **0.0× – 2.8× 踏频调节**。
   - **晨光海岸 / 落日橘海 / 星夜灯塔** 三种海岸光影实时切换（夜色模式下开启车灯照明光束与旋转灯塔光柱）。
   - **道具开关**：条纹围巾、复古护目镜、海风气流线。
   - **叮铃鸣笛**：点击「叮铃鸣笛」按钮或直接点击画布中的铜铃/鹈鹕头部，触发 Web Audio 合成清脆双音车铃声与鹈鹕喉囊轻晃。
   - **导出当前帧 SVG**：可将当前光影与配饰状态直接保存为独立 `.svg` 矢量文件。

## 本地预览

直接在浏览器打开 `pro4/index.html` 或 `pro4/pelican-bicycle.svg` 即可查看，也可启动任意静态文件服务：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/pro4/
```
