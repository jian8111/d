## Cursor Swarm × GitHub 配置说明

1. **Cursor IDE / CLI 本地多智能体蜂群**：
   - 使用 Cursor 打开本仓库即自动加载 [`.cursor/rules/`](./.cursor/rules) 与 [`.cursor/agents/`](./.cursor/agents)。
   - 在 Agent 对话中输入 `/swarm <目标>`，主控代理会按互不冲突的目录切片派发 `swarm-worker` 并行开发，并调用 `swarm-verifier` 与 [`verify_repo.py`](./.cursor/skills/swarm-verify/scripts/verify_repo.py) 完成全量校验。
   - 如需在 MCP 中启用 GitHub Server，在本地导出 `GITHUB_PERSONAL_ACCESS_TOKEN` 环境变量即可（[`.cursor/mcp.json`](./.cursor/mcp.json) 使用 `${env:...}` 占位，不存放明文密钥）。
2. **GitHub Actions 与 GitHub Pages**：
   - **GitHub Pages**（[`.github/workflows/pages.yml`](./.github/workflows/pages.yml)）：在 GitHub 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，推送 `main` 后即自动发布 `pelican-6000-mv.html` 原创纯代码 MV、`pelican-6000/index.html` 模块化源码工程、`pelican-6000-pure-code.html` 纯代码全片、三部 CursorSwarm 作品、`index.html`、`pelican-swarm-demo.html`、`swarm-demo.html`、Codespace 提取作品与 `pro1/`–`pro6/`。
   - **Cursor Agent Swarm CI**（[`.github/workflows/cursor-agent-swarm.yml`](./.github/workflows/cursor-agent-swarm.yml)）：配置仓库 Secret 后可通过 `Actions → Cursor Agent Swarm CI` 手动触发，或在 Issue/PR 评论中输入 `/swarm <任务>` 自动开分支并发起 PR：
     ```bash
     gh secret set CURSOR_API_KEY --repo jian8111/d --body "$CURSOR_API_KEY"
     ```
3. **本地校验与预览**：
   - 运行校验：`python3 .cursor/skills/swarm-verify/scripts/verify_repo.py --strict`
   - 本地预览：直接打开 [`index.html`](./index.html)、[`pelican-6000-mv.html`](./pelican-6000-mv.html)、[`pelican-6000/index.html`](./pelican-6000/index.html)、[`pelican-6000-pure-code.html`](./pelican-6000-pure-code.html)（原作 v1.1.0 纯代码单文件版）、[`cursor-swarm-city.html`](./cursor-swarm-city.html)、[`cursor-swarm-foundry.html`](./cursor-swarm-foundry.html)、[`pelican-swarm-coaster.html`](./pelican-swarm-coaster.html)、[`pelican-swarm-demo.html`](./pelican-swarm-demo.html)、[`pelican-ride.html`](./pelican-ride.html)、[`pelican_bike.html`](./pelican_bike.html) 或 [`swarm-demo.html`](./swarm-demo.html)。所有页面均为零外部依赖，支持离线运行；纯代码全片点击画面解锁声音并播放。
   - 使用静态服务器预览纯代码全片：
     ```bash
     python3 -m http.server 8787 --bind 127.0.0.1
     # 浏览器打开 http://127.0.0.1:8787/pelican-6000-pure-code.html
     # PRO2H 原创 MV：http://127.0.0.1:8787/pelican-6000-mv.html
     # 模块化源码工程：http://127.0.0.1:8787/pelican-6000/index.html
     ```
   - `pelican-6000-mv.html` 可直接离线打开；`pelican-6000/index.html` 推荐使用上述静态服务器加载 ESM 模块。
