# Pro2 — Pelican on a Coastal Ride

![Pelican Riding a Bicycle](./pelican.svg)

## Files

- [`index.html`](./index.html) — Self-contained interactive HTML5 page featuring an inline SVG pelican riding a vintage teal bicycle along a coastal boardwalk, with real-time 2-bone inverse kinematics (IK) pedaling, seamless parallax scrolling, mood switching (`落日栈道` / `晴朗清晨` / `灯塔暮色`), synthesized Web Audio brass bell chime, and one-click SVG export.
- [`pelican.svg`](./pelican.svg) — Standalone vector SVG artwork (`960×600`).
