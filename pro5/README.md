# pro5 · 鹈鹕骑车（Pelican Riding a Bicycle）

使用纯矢量 **SVG + 自包含单文件 HTML5** 构建的「鹈鹕骑自行车」交互式插画版本，所有文件独立整理在 `pro5/` 目录中。

![Pelican Riding a Bicycle](./pelican-bicycle.svg)

## 目录结构

```text
pro5/
├── README.md            # 本说明文档
├── index.html           # 零依赖单文件交互式展示页（5 场景预设 + 实时 2-Bone IK + 车铃音效 + SVG 导出）
└── pelican-bicycle.svg  # 800×520 纯正静态矢量 SVG 源文件（无滤镜依赖，兼容 GitHub / Figma / librsvg）
```

## 核心亮点

1. **精确几何与双连杆 IK 踩踏耦合**
   - 严格按照公路/海岸巡航车几何参数建模：`73.5°` 立管角、`72.1°` 头管角、`330px` 轴距、`28` 齿牙盘与切线链条传动、交叉辐条、复古棕边胎与前后挡泥板。
   - 鹈鹕双腿由实时 **2-Bone Inverse Kinematics (IK)** 求解，在 `0.2× – 2.8×` 踏频下始终保持双脚蹼精准踏在左右脚踏上，同时伴随自然身体微幅起伏、围巾海风飘动与眨眼动画。

2. **海滨鹈鹕造型细节**
   - 标志性长上喙配珊瑚红钩状喙尖、立体渐变的琥珀金喉囊、奶油金胸羽、深灰翼尖飞羽抓握车把、以及车前竹编车篮里探头的小海鱼。

3. **5 套主题场景与交互控制**
   - **1. 海滨晴日** · 明亮海岸栈道、灯塔、帆船与浮动白云
   - **2. 落日余晖** · 暮色橘紫渐变天际与暖色海岸光线
   - **3. 星夜骑行** · 星空新月与车前复古车灯照明光束
   - **4. 工程蓝图** · CAD 网格标尺与实时曲柄角 / IK 膝关节坐标遥测
   - **5. 极简画廊** · 纯净画廊展板，便于检查矢量轮廓与导出
   - 快捷键：`Space` 暂停/继续 · `1–5` 切换场景 · `B` 按响 Web Audio 铜车铃 · 一键复制/下载当前帧 SVG。
