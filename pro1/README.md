## 亮点特性

1. **真实自行车几何与双连杆 IK 踩踏**
   - 严格按经典钻石三角车架、`72.9°` 立管角、`73°` 头管角、`166px` 轴距建模，配备前后挡泥板、切线链条传动、牙盘与 `16` 根旋转辐条。
   - 鹈鹕双腿采用实时 **2-Bone Inverse Kinematics (IK)** 求解，脚蹼紧贴左右脚踏板完整旋转一周；轮组转动线速度与地面虚线滚动严格匹配，无滑步。

2. **鹈鹕生理特征与彩蛋互动**
   - 长 S 形颈部、冠羽、金黄眼周斑、标志性红橙钩状上喙与橘琥珀色弹力喉囊、黑尖白底初级飞羽抓握车把、橘色三趾蹼足。
   - **互动彩蛋**：点击**鹈鹕**会张嘴眨眼甩出喉囊里的小海鱼；点击**黄铜车铃**（或按 `B`）播放 Web Audio 合成双音铃声并飘出音符。

3. **主题与快捷控制**
   - 支持 `海岸晴空 / 金色落日`（`M`）切换（落日模式自动点亮车前复古车灯光束）、`Space` 暂停/继续、`0.3×–2.5×` 调速，以及一键复制/下载当前帧 SVG。
