CURSOR × GITHUB SWARM

从静态画廊到多智能体协同工作区

本仓库同时集成了前端多光标构建引擎（assets/vendor/cursor-swarm/cursor-swarm.min.js，MIT 协议零依赖）与Cursor Agent Swarm 工程规范（.cursor/rules、.cursor/skills、.cursor/agents、.cursor/hooks.json、.cursor/mcp.json 及 .github/workflows/）。

在 Cursor 中直接输入 /swarm 即可按无冲突切片调度并发子代理，并通过 GitHub Actions 自动部署 GitHub Pages 或触发 Cloud Agent PR。

.cursor/rules/*.mdc

4 层协作与协同规则

固化 AGENTS.md 50MB 防超限与双署名铁律、Swarm 切片解耦协议、零 CDN 前端规范与 pstack 模型路由。

.cursor/skills/

/swarm 与自动校验技能

提供 swarm/SKILL.md（Frame → Fan out → Aggregate → Report）、swarm-verify 与 cursor-swarm-ui。

.cursor/agents/

4 个专职子代理

内置 swarm-planner、swarm-worker、swarm-verifier 与 github-sync-reviewer，支持后台隔离执行。

.github/workflows/

Pages + CI + Swarm CLI

自动运行 verify_repo.py --strict、发布静态站到 GitHub Pages，并支持 /swarm 评论触发 Cursor CLI PR。

QUICKSTART CLI

GitHub 端启用与触发命令

# 1. 为 GitHub Actions Cursor Swarm 配置 API Key Secret
gh secret set CURSOR_API_KEY --repo jian8111/d --body "$CURSOR_API_KEY"

# 2. 在仓库 Settings → Pages 中将 Build and deployment Source 设为 GitHub Actions
# 3. 本地校验所有 Cursor 配置、SVG 与 50MB 规则
python3 .cursor/skills/swarm-verify/scripts/verify_repo.py --strict
